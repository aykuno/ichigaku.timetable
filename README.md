# 2026年度 時間割検索（パスワード暗号化）

添付の時間割コードを登録しています（61クラス・教職員173名）。
パスワードで開くと、クラス・教職員の時間割、所属や担当、授業条件検索を利用できます。
クラス名で検索した結果は「クラス時間割 → 担任 → 副担任」の順に表示します。
閲覧用パスワードは管理者のチャットにだけ伝え、このリポジトリやCIには保存しません。
404ページはデータ未登録のまま、入力・閲覧を無効にしています。

## 2画面で比較

通常は1画面です。上部の「2画面で比較」を押すと、PCでは横並び、スマホなど幅760px以下では縦並びになります。
各画面でクラス・教員や授業条件を別々に検索・選択できます。
「1画面に戻す」で通常表示に戻り、再び2画面にすると両方の選択を保持しています。
画面サイズを変えても選択は維持し、ログアウト・再読み込み時は両方を消して1画面に戻ります。

## 検索・比較・保存・PDF

- 空き教員検索：曜日・時限・教科・担当学年で絞れます。「空き」「指定休・休み」「データ・勤務要確認」「授業・予定あり」を分けます。
- 共通空き：教員を2人以上選択します。表示中の教員、担任＋副担任、2画面で選択した教員を取り込めます。
- セルの逆引き：クラス表の担当教員、教員表の授業先クラスを押して移動します。複数候補は選択し、データのない時間割へのリンクは作りません。
- 比較差分：2画面の「差分表示」を切り替えます。緑＝共通空き、黄＝一部に予定、赤＝全員に予定、青＝同じ授業に関係、灰＝指定休・休み・勤務要確認です。
- お気に入り・最近見た5件：端末のlocalStorageへAES-256-GCMで暗号化して保存します。2画面の操作を統合し、「お気に入り・履歴を消す」で削除できます。再ログイン時に同じパスワードで読みます。
- 教員プロフィール：担当科目・クラス・担任/副担任・所属/役職を、登録済み時間割から集計します。教科・担当学年は授業内容からの集計で、公式の所属表の追加ではありません。
- PDF：表示中の時間割をA4・1ページで端末内に生成します。共テサイトの現行 `kyoutu-ui-lab/pdf-export.js` のCanvas/JPEG・PDFオブジェクト/xref作成方式とファイル共有方式を応用しています。iPhoneは共有シートで「ファイルに保存」、他の端末はダウンロードできます。保存画面はログアウト時に閉じ、Blob URLも失効します。

空きの判定は時間割上の空欄を使います。教科部会・主任会議・ICRなど記載があるコマは予定ありです。
指定休、複数日の休み、産休、実施日のみ出勤という記載を空きと混同しません。

## 時間割を先に表示

検索のすぐ下に時間割を表示します。スマホの検索結果は横スクロールする1行です。
お気に入りは登録済みの場合だけ1行で表示し、最近見た時間割・保存設定と追加の検索機能は時間割の下へ移しました。
教員の詳しい担当・所属は折りたたみで開きます。

既存の暗号文と閲覧用パスワードを保ったまま、復号後に表示だけを更新します。
復号後のスクリプトにも固定のCSPハッシュを指定し、外部通信の制限を継続します。

## 「今」表示の標準時刻

中学・高校共通の授業時刻を設定済みです。日本時間で現在のコマと次の授業を表示します。

| 時限 | 開始 | 終了 |
| --- | --- | --- |
| 1 | 8:35 | 9:25 |
| 2 | 9:35 | 10:25 |
| 3 | 10:35 | 11:25 |
| 4 | 11:35 | 12:25 |
| 5 | 13:10 | 14:00 |
| 6 | 14:10 | 15:00 |
| 7（木曜のみ） | 15:10 | 16:00 |

「時刻を設定」で端末ごとに変更でき、「標準時刻に戻す」で上記に戻ります。
週時間割にない臨時変更・休校は自動反映しません。

## 追加した仕組み

- 時間割HTML全体をAES-256-GCMで暗号化します。
- 鍵はPBKDF2-HMAC-SHA-256（600,000回）でパスワードから作ります。
- 元のHTMLやパスワードを公開リポジトリに置かず、生成した暗号文を登録します。
- 正しいパスワードでのみ復号し、操作しない状態が30分続くと表示を消します。
- パスワードや時間割本体を端末ストレージに保存しません。お気に入り・履歴・時刻だけ、別の塩・鍵を使って暗号化してlocalStorageに保存します。
- 復号したHTMLはsandbox iframe内で実行し、外部通信をCSPで制限します。

## 検索結果への掲載を避ける設定

index.html、404.html、生成テンプレートに次のタグを設定しています。

    <meta name="robots" content="noindex,nofollow,noarchive,nosnippet">
    <meta name="googlebot" content="noindex,nofollow,nosnippet">

robots.txtに、`/ichigaku.timetable/` のクロールを拒否するルールも追加しています。
ただし、robots.txtはホストのルート（`https://aykuno.github.io/robots.txt`）で配信する必要があり、
このリポジトリから出る `/ichigaku.timetable/robots.txt` は有効なクロール制御にはなりません。
ホストのルート配信元は今回の操作範囲にないため、現在はnoindexが検索対策です。
将来ルートへ設置するとGoogleがnoindexを読めなくなる場合があり、robots.txtだけではURLの検索掲載を防げません。

noindexは、対応する検索エンジンに掲載しないよう指示する設定です。
URLを秘密にする機能でも、アクセス制限でもありません。
リポジトリ自体は現在publicです。GitHub上のリポジトリの検索掲載はこのタグでは制御できません。
時間割の中身は別途パスワード暗号化で保護します。
正規の閲覧者によるコピー・転送は防げません。
暗号文へのオフラインのパスワード推測や、保存済みの過去の暗号文を失効させることにも対応できません。

## 公開

この変更ではPagesを有効化する操作はしていません。
公開する場合はSettings → Pagesを開き、以下を選びます。

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

## 後でデータを登録する場合

Node.js 22以上で、管理者のPCから実行します。
元のコードはGitの対象外であるprivate/timetable.txtに保存します。

    node tools/build.mjs private/timetable.txt

暗号化済みindex.html、index.txtと、準備中のままの404.htmlを生成します。
新しいパスワードはローカル端末に表示します。公開ログやコミットに記録しないでください。
パスワードを指定する場合はTIMETABLE_PASSWORD環境変数へ24文字以上の長い値を設定します。
未指定時は暗号学的乱数から32文字のパスワードを生成します。
CI上で実行しようとすると、秘密情報を公開ログへ出さないため停止します。

## コードと検証

index.txtはindex.htmlと同じ内容の、コード保存用のファイルです。
HTMLのプレビューは不要です。

    npm install --ignore-scripts --no-audit --no-fund
    npm test
    npx playwright install --with-deps chromium webkit
    npm run test:browser
    npm run test:timetable
    npm run test:features

検証には架空のテストデータだけを使います。
